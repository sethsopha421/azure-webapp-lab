# Azure Web App Lab

This is a sample web application deployed to **Microsoft Azure App Service** with continuous deployment from **GitHub**.

## 🎯 Learning Objectives

- Create an Azure Web App
- Connect GitHub repository to Azure
- Configure automatic deployment using GitHub Actions
- Update code and trigger auto-deployment

## 🚀 Technologies Used

- HTML/CSS/JavaScript
- Microsoft Azure App Service
- GitHub Actions (CI/CD)
